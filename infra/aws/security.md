# 보안

누가 어떤 서버의 어떤 포트에 접근할 수 있는지 정합니다.

## 보안 그룹

EC2에 붙이는 가상 방화벽입니다. 허용한 인바운드만 들어올 수 있고, 응답 트래픽은 자동으로 허용됩니다.

### `web-sg` (웹 EC2)

| 유형 | 포트 | 소스 | 이유 |
| --- | --- | --- | --- |
| HTTP | 80 | `0.0.0.0/0` | 누구나 게시판 접속 |
| SSH | 22 | 내 IP | 서버 작업 및 DB EC2 접속용 Bastion |

### `db-sg` (DB EC2)

| 유형 | 포트 | 소스 | 이유 |
| --- | --- | --- | --- |
| MySQL/Aurora | 3306 | `web-sg` | 웹 EC2의 앱만 DB 접근 |
| SSH | 22 | `web-sg` | 웹 EC2를 거쳐서만 SSH 접속 |

> 소스를 IP 대역이 아니라 **보안 그룹(`web-sg`)으로 지정**하는 것이 2-Tier의 핵심입니다. 웹 EC2의 IP가 바뀌어도 규칙을 고칠 필요가 없고, `web-sg`가 붙은 서버만 DB에 닿을 수 있습니다.

## 키 페어

EC2에 SSH로 접속할 때 쓰는 인증 키입니다. 생성할 때 한 번만 다운로드할 수 있습니다.

| 항목 | 값 |
| --- | --- |
| 이름 | `board-key` |
| 유형 / 형식 | RSA / `.pem` |
| 사용 | 웹 EC2, DB EC2 공용 |
